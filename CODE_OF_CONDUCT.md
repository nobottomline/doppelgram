# Code of conduct

Be respectful and constructive. Discuss code and ideas, not people.

Not acceptable here: harassment, insults, discrimination, sexualised language or imagery, publishing anyone's
private information, and using this project or its issue tracker to target, deceive or expose real people.
That includes posting other users' profiles, photos, names or chats from dating bots, even as "examples".

Maintainers may edit or remove content and block participants who break these rules. Report problems
privately through GitHub's *Report content* or a private security advisory (see SECURITY.md).

This code is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/).
